## Workflow Feedback

| Field | Value |
| --- | --- |
| Category | `input/source/identity/conversion/dimension/semantics/description/validation/usability/upstream` |
| Candidate | `unit expression or all` |
| Observation | What happened, stated without speculation |
| Evidence | Source, validation output, or upstream review |
| Impact | What decision or artifact was affected |
| Frequency | First occurrence or known recurrence |
| Proposed change | Smallest generalizable improvement |
| Disposition | `accepted/rejected/deferred/needs-evidence` |
